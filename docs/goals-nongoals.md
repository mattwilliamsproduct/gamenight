## Goals

- Crush requirements so the next one-shot is better after every correction.
- Coding OS runs plan, then implement, then prove-it, then compound.
- Back Porch is a commercial-quality resume showcase for logic, design, architecture, and intentional interactions.
- Agents own the process. Matt owns taste, kill, the morning UI prove-it, and undraft or merge.

## Non-goals

- A classifier does not undraft or merge an app or product PR.
- A process doc does not rewrite `docs/product-spec.md`.
- Grok is not the primary redesign designer until a later Grok proves design excellence. Opus writes the plan first. The handoff fields are in `docs/redesign-checklist.md`.
- Do not buy Jev or Gateway credits without a logged sample of about 20 runs in `docs/solutions/gate-log.md`.
- Chat is not the system of record.

## Kill criteria

A slice fails when any of these are true:

- It claims ready to test without a phone look and a filled `docs/prove-it-packet.md`.
- A name is truncated, the keypad covers a row, or a total leaves the phone.
- Durable Matt feedback stays only in chat.
- A second Cloud Agent thread works the same app PR without an explicit owner switch.
