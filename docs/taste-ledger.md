# Taste ledger

Likes and kills for Back Porch. The same list opens `docs/taste.md`. After every durable Matt correction, add one like or one kill bullet the same day in this file and in that section. Do not leave the correction only in chat.

Seeded from Prefer, Avoid, and Kill in `docs/taste.md`. Product rules stay in `docs/product-spec.md`.
