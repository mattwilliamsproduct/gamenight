# End screen uses the records rules

An ended-early night that is not counted says Ended early. It does not name a winner, fire the winner celebration, or list a new score. Needs review uses those words instead. A counted night can still name the winner. A partial total never sets a score record, and a left-early total never does either.

Tied career lists share rank 1, 1, 3. A closest margin of 0 names every tied player.
