# Home Recent nights column

Matt did not like the white space between Tonight's Table and Recent nights at laptop width. The table ended above the taller Start a New Match card, then Recent nights sat full-width below both columns.

## Rule

Two-column Home starts at 861px (the existing `max-width: 860px` stack). At that width and up, Recent nights sits in the left column under Tonight's Table as a compact list: game, date, winner. Start a New Match stays in the right column and spans the left stack. Phone keeps Table, then Start, then nights.

Zero nights omits the section. Do not invent a placeholder to fill the left column.

## Kill

A full-width Recent nights card under a two-column Home, or a dead block in the left column between the table and the next full-width band.
