# Five Crowns designed back

Matt's photo is the reference for the real Five Crowns back. It is not the picker face.

The Home face is a clean 700×980 SVG raster (`public/assets/cards/five-crowns.svg` → `five-crowns.webp`). Canasta sets the polish: flat color, crisp type, edge to edge, no photo grain. The mark still has to read as Five Crowns: deep purple lattice, lighter-purple gold-edged band, sideways gold-and-red FIVE CROWNS logo with the crown cluster on the left. No copyright. The tagline stays off unless it is crisp at 2×.

Do not retouch, warp, or straighten the photo. Do not run `fit-card-faces.py` on this face; it is already 5:7.

Rook and Beat the Heat defaults are the edge-filled faces. Pads use background only so a crow tail or pepper flame does not repeat at the edge.
