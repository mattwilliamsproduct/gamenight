# Dusk game tiles

Quiet back-porch vignettes for `?demo&art=dusk`. Default Home still uses `public/theme/game-card-*-thumb.jpg`.

Drop Matt's rasters here as WebP. The CSS prefers `.webp` and falls back to the SVG stand-in.

| Game | Slug | Motif in this repo | Assumption |
| --- | --- | --- | --- |
| Five Crowns | `five-crowns` | Five crown suits; rummy; 11 hands; low score wins | Five crowns, not a beach table |
| Wizard | `wizard` | Wizard hat / Wizard card; exact-bid tricks | One hat, no tiki mug |
| 818 | `818` | House 8-1-8 bid/trick race (8 down to 1, back to 8). Not a published box in this repo | Hourglass card pile = the 8-1-8 shape. No giant 818 numerals |
| Flip 7 | `flip-7` | Flip cards, bank before a bust, enter the banked score | One 7 card. The flamingo in the current tile is porch decor, not the game |
| Beat the Heat | `beat-the-heat` | Pepper heat; low score; match ends at 66 | One chili |
| Rook | `rook` | Call-your-partner Rook; bird / Rook card; teams | Rook bird on a rail, not a chess piece |

Hero sits in the middle of a 800×400 frame so a short Home crop still shows it.
